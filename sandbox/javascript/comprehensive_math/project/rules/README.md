## 目录用途与边界

仅用于：javascript / comprehensive_math 案例的该项目的自定义 Rule / Ruleset 声明与检查实现；不放 VibeFlow 产品内置规则。

- 新文件按上述用途归属；新增子目录同时写明职责，不能作为临时收纳箱。

- 已确定过时且不再使用的内容直接删除；需要追溯时使用 Git 历史，不默认另建归档。
