# src/vibeflow/targets/shared/rule_support

## 目录用途与边界

仅用于：各 Target 内置规则复用的算法、政策、Record 契约和 Plugin 装配辅助；不保存 Rule/Ruleset 资源声明。

- 运行日志、缓存、依赖安装和候选构建放在仓库外临时工作区。
- 新文件按职责归置；过时内容由 Git 历史追溯，不保留旧路径兼容层。

完整归位规则见[仓库目录职责](../../../../../docs/maintainers/directory-layout.md)。
