## 目标与执行

用户确认：已确定过时且不再使用的材料直接删除，不默认复制到外部归档。保留当前测试输入、仍有阅读用途的开发说明和工作簿。沙盒继续加载工作区 src。

1. 核对 resource_migration 的运行引用及工作区改动，删除 446 份已退役输入，去掉审计工具豁免和活动文档的旧指引。
2. 删除已被中文盘点和 Git 源码替代的审核机器索引、源码全文摘录、收集输出；历史统计保留当时口径，不改写成当前成绩。
3. 工作簿归入 docs/assets/audits，已完成审核及 Rule 重构实施记录归入 docs/maintainers/history；更新阅读导航和相对链接。

## 执行中的成本、目标与路线复核

关键假设是旧资源没有加载方、机器索引属于可替代的历史输出，而固定 SDK 项目和沙盒仍是活动输入。主要成本是引用修正及定向验证，文件删除本身成本较低；最近完整门禁约 40 分钟，纯资料整理先运行相应检查，不默认重复全量。

在删除前引用核对、首次归位后的链接检查、定向验证结束和交付前，复核剩余工作量、验证代价、维护负担与上述假设。若发现所谓旧资料仍被加载，保留该项并核实用途；明确错误和等价修正自主完成。若证据要求改变当前用途、保留目标或验收范围，按 critical-fork 先核查，再用中文说明因果、结果、成本和未知，征求用户判断；说明准备好后按 codex-task-alert 的资格规则提醒。只暂停依赖决定的部分，继续独立工作，得到决定后更新本记录。

本轮不另建删除材料的副本或归档；Git 已保存的旧资源仍可通过历史提交追溯。活动工作区的产品和测试改动以开始时的逐文件指纹核对，既有外部证据不在本轮删除范围内。
