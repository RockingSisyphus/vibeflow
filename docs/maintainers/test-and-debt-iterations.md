# 测试提效与技术债迭代

## 目标与基线

用户于 2026-10-21 授权无人监督期间自主推进普通修复；会导致项目结构大变的决定先留档暂缓。开始提交为 `155ec87`，此前修复已完成 18/18 完整门禁；默认测试并发随后改为 12，并经 44 项定向验证。版本号、正式 dist、远端分支和 Release 不在本任务范围。

基线证据为仓库旁 `VibeFlow-evidence/technical-debt-20261021/full-2-*`：完整门禁 1480.4 秒，其中规则回归 757.9 秒；JS 集成 170.3 秒、pytest 149.2 秒、Python 沙盒 105.7 秒、适配回归 88.8 秒。规则资源的 display/edits 两组内部串行形成长尾，调高最大 worker 数不能单独消除这一问题。

## 实施与每轮提交

1. **测试调度与断言整理。** 将可独立的 display/edits 工作按资源类别分配到同一个有上限的队列，保持每个修改—验证—恢复案例内部顺序。保留案例身份、正反控制与真实浏览器，不以跳过昂贵用例换取提速。检查过时的发射源码字节摘要断言，保留公开接口、计划及真实执行的独立保护。定向验证后单独提交。
2. **覆盖与技术债审查。** 按 Core/Block Compiler、两端 Target、Coordination、Tooling/展示、发行/文档、测试夹具逐项检查真实调用链。删除证实无调用且无公开契约用途的旧路径，收拢已分离职责，更新当前文档；历史基线、迁移诊断与有效可选 SVG 覆盖不因名称含旧接口就删除。针对发现的真实行为缺口补充回归，完成定向验证后提交。
3. **集成验收与复核。** 使用默认 12 workers 运行正式完整门禁，与基线分别比较各阶段耗时、案例删增依据和观察数量。保留所有失败批次，集中修复并定向复验后进行必要的完整复验。验收、文档与清理完成后提交收尾；尚需用户决定的结构性事项列出证据、方案及影响。

不以一定要删掉多少测试、增加多少模块或达到未经实测的秒数为完成标准。完成标准是：已审查范围的可自主修复问题闭环，覆盖删增有具体依据，实际效率已测量，必要门禁通过，每轮提交可追溯，结构性待决事项明确。

## 执行中的成本、目标与路线复核

主要成本是资源展示中的真实编译/浏览器运行及完整回归；先依据已有逐阶段耗时处理长尾，不增加另一套测试资格、锁或复杂调度框架。关键假设是：资源类别之间的项目和进程状态独立；旧源码字节快照没有额外业务语义；已有 Architecture/规则入口足以支撑新增覆盖，不需要大改产品结构。

在首个拆分资源批次、删改断言后的行为验证、技术债调用链审查完成，以及最终完整门禁后，复用实测证据复核剩余工作、验证代价、维护负担和假设。若实践推翻假设，按 critical-fork 重新判断；常规等价实现自主处理。用户休息期间，确需改变产品结构的选项先做低成本核查并留档，写清同一场景下各路线结果、机制、代价和未知；只暂缓依赖该决定的工作，继续独立任务。恢复讨论后更新本计划和验收依据。

实际使用目标模式，整项目标与必要验收完成后按 codex-task-alert 发送一次完成提醒。确需用户介入的事项先在聊天完整说明，再按其资格规则提醒；普通失败和进度不提醒，不用通知代替诊断。

### 第一轮：调度与过时断言

- display/edits 分别按四种资源及额外案例拆分，总队列由 11 项变为 19 项；只使用外层有上限的队列，删除旧环境变量分派及备用嵌套线程池。每个案例仍在独立子进程中通过真实 CLI/浏览器观察，修改与恢复序列不拆开。
- 退役 JavaScript emitter 的 9 份完整源码字节摘要：上一轮仅修剪 helper 文件末尾空行就必须更新，不能独立证明用户语义。保留声明、公共计划、导出接口及真实执行测试。
- 删除 `deferred` 发射案例：迁移成普通 SDK 异步节点后，它与 `async` 的完整计划、声明和源码均完全相同。保留 async 覆盖；原 detached 案例改称 suspending_no_output，继续验证无业务输出的异步执行。
- 实测：定向测试 27 项通过；规则一致性 1,210/1,210，补充规则 680/680，无进程错误。案例 ID 完全相同，预期值仅 16 例的临时工作根路径不同，归一化该根路径后全部相同。
- 同一次本机运行中，规则一致性耗时 106.2 秒、补充规则 289.2 秒，合计 395.4 秒；此前同阶段 757.9 秒，下降约 47.8%。这反映任务拆分与默认 12 workers 的合并效果，不当作两者独立因果倍率；完整门禁总耗时尚待最终实测。证据在 `VibeFlow-evidence/test-debt-iterations-20261021/round1-*`。
