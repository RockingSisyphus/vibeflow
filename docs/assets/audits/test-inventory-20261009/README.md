## 目录用途与边界

仅用于：2026-10-09 测试盘点的长期阅读工作簿；不继续追加后续运行的原始产物。

- 新文件按上述用途归属；新增子目录同时写明职责，不能作为临时收纳箱。

- 已确定过时且不再使用的内容直接删除；需要追溯时使用 Git 历史，不默认另建归档。
