# 执行模型

Core 提供语言无关的图结构与依赖；Block Compiler 生成 Workflow ABI v12 的普通工作流、Nodeset 与 Loop Block。Target 负责真实执行，Tooling 负责配置、质量检查与展示。

所有执行节点通过正常边激活下游。就绪队列提交独立分支；节点完成真实清理后交付输出；`join_policy: all` 消费本轮所有前驱的完成信号再执行。分发节点通过 `config.max_concurrency` 设置自身直接调用的容量，默认 8，任一调用实际退出后补位。串行关系由依赖链表达。

Python 的 plan、block、compiled 三种入口共用同一图调度器；JavaScript AOT 发射事件循环调度。锁保护与取消生命周期覆盖已启动节点至实际退出，错误保留清理信息。详细配置与迁移见[普通图并发与汇合](graph-concurrency.md)。

## 失败、取消与后续错误

Python 运行时的 `errors.py` 统一异常附加和收尾规则，现有 `CancellationSignal` 保存本次运行最先确认的失败或外部停止来源。节点在可能挂起的失败回调和资源收尾之前登记原错误；内部 Nodeset / Loop 共享来源，独立 workflow 仍拥有自己的运行。登记错误不等于执行已结束，调度器仍停止并等待已启动任务及线程真正退出。

业务失败引发的取消不替换原业务异常；外部先取消时，随后清理失败仍附加到取消异常。失败回调、释放、日志摘要和观察流关闭出错时保留已有主异常，其他收尾继续执行；没有已有异常时，收尾失败正常向调用方报告。同步调用保留原异常对象和类型，不为统一而包装成新的万能异常。

其他并发分支独立发生的业务异常保存在 `execution_errors`，真实收尾异常保存在 `cleanup_errors`，同一异常对象不因穿过多个嵌套层重复追加。Coordination 不以“曾请求停止”代替最终执行结果；它只转换最终异常和终态，不决定 Target 内部的错误优先级。Python 隐式上下文仅作为诊断传输，并遵守 `raise ... from None`，不据此猜测主错误。

授权的 CLI 退出仍按控制流返回退出码；若其已拥有的资源在收尾时失败，则报告真实清理异常，并以 `business_exit` 保存原退出码和来源。停止观察者的失败也作为清理错误保留，不中断其他收尾。


`global_state` 表示调用会影响进程内共享状态；它不会自动建立所有根图共用的全局串行队列。需要排他访问的工作应明确声明 `execution_lock`，并使用同一业务域的锁键。父作用域持锁时，子作用域不能换用不兼容的键；发生异常或取消也要先等真实执行和清理结束，再释放租约。

Python 的 `vibeflow.global_state` Ruleset 通过 `vibeflow.no_side_effects` 的 `effect_scope="global_state"` 允许运行时读取、修改和恢复环境变量：`os.environ` / `os.environb` 的键访问及方法，以及 `os.getenv` / `os.getenvb`、`os.putenv`、`os.unsetenv`。不限制环境键名；不会自动保存或恢复原值，生命周期实现仍须负责恢复。普通 Node、BaseLib、继承/helper 与运行插件共用该效果检查；插件须显式将其 effects 调用参数设为 `global_state`，流程类别名称本身不授予权限。显式 import policy 仍然生效，导入时执行检查保持不变。

该授权不包含替换 `os.environ` 对象、修改 `sys.path` 等导入状态，或文件、网络、子进程和线程操作；`process`、`io`、`python_io`、`data_store` 的默认规则不因此放开环境变量操作。

旧 `async`、`detached`、`result_key` 调度字段已撤销，隐藏目标必须改成普通节点与显式连接。工作流执行探针用于核对图、契约、分支和清理行为；它通过不等于证明业务结果正确性，业务断言仍需由项目提供。

## 命名入口与运行范围

`pipeline.entries` 选择起始 terminal 和该入口可达的调度路径，可覆盖公开输入输出；多个入口复用同一核心节点。审查和构建检查完整图，连任何入口都无法到达的孤立节点仍报错；各入口分别检查契约与汇合。源码运行只对所选入口及其实际引用的 Nodeset / Loop 定义做执行前图检查，未选入口的 planned 内容不会阻止已实现入口运行。模块装载、源码绑定和全图编译的原生错误仍会报告，不以入口选择跳过。

AOT 在构建时保存每个入口的范围和策略，运行时直接选择已准备计划，不重新编译或审图。Python 源码运行历史记录实际入口；HTML 首次打开该记录时默认显示此入口，用户可切换其他入口查看。
